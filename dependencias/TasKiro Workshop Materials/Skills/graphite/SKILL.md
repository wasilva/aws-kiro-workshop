# Graphite — frontend style skill

This skill guides creation of distinctive, production-grade frontend interfaces that avoid generic "AI slop" aesthetics. Implement real working code with exceptional attention to aesthetic details and creative choices.

## Design Thinking

Before coding, commit to this aesthetic direction:

- **Purpose**: What problem does this interface solve? Who uses it?

- **Tone**: Graphite — Lean into functional mono: engineer's elegance, the Berkeley Mono / Geist Mono / Vercel-CLI aesthetic. ONE monospace typeface throughout (JetBrains Mono, Geist Mono, or IBM Plex Mono via Google Fonts): headings, numbers, labels, everything mono. Pure GRAYSCALE — near-black ink on warm paper-white or `#FAFAFA`. ONE single restrained accent (a calm blue `#2563EB`) used only for the active/positive state. CRITICAL: NO neon, NO glitch, NO scanlines, NO glow — this is the explicit OPPOSITE of cyberpunk; it is calm, quiet, precise. Tabular numerals with perfectly aligned columns, hairline 1px rules, generous letter-tracking on small uppercase labels. A command-palette-first feel: a subtle "⌘K" affordance, keyboard-hint chips, a top command bar. Dense but calm — a beautifully typeset terminal, Linear-meets-CLI. Monospace block characters (▁▂▃▄▅▆▇█) may build sparklines and bars — elegant, never kitschy. The beauty comes from precision, alignment, and typographic discipline, not decoration. The one thing someone remembers: the entire UI reads like a perfectly typeset instrument.

- **Differentiation**: What makes this UNFORGETTABLE within this style? What's the one thing someone will remember?

**CRITICAL**: Execute this style with precision and intentionality. The key is bold commitment to the aesthetic, not generic interpretation.

Then implement working code (HTML/CSS/JS, React, Vue, etc.) that is:

- Production-grade and functional
- Visually striking and memorable
- Cohesive with a clear aesthetic point-of-view
- Meticulously refined in every detail

## Frontend Aesthetics Guidelines

Focus on:

- **Typography**: Choose fonts that are beautiful, unique, and interesting. Avoid generic fonts like Arial and Inter; opt instead for distinctive choices that elevate the frontend's aesthetics — unexpected, characterful font choices. In this style that means committing to a single excellent monospace family and earning all hierarchy from scale, weight, tracking, and case rather than from mixing typefaces.

- **Color & Theme**: Commit to a cohesive aesthetic. Use CSS variables for consistency. Dominant colors with sharp accents outperform timid, evenly-distributed palettes. Here: warm paper-white or `#FAFAFA` surface, near-black ink, and the single calm blue `#2563EB` reserved for the active/positive state only.

- **Motion**: Use animations for effects and micro-interactions. Prioritize CSS-only solutions for HTML. Use the Motion library for React when available. Focus on high-impact moments: one well-orchestrated page load with staggered reveals (`animation-delay`) creates more delight than scattered micro-interactions. Use scroll-triggering and hover states that surprise — but keep them quiet and precise, never flashy.

- **Spatial Composition**: Unexpected layouts. Asymmetry. Overlap. Diagonal flow. Grid-breaking elements. Generous negative space OR controlled density. For Graphite, favor controlled density with perfect alignment: tabular columns, hairline rules, and a command-bar / palette structure.

- **Backgrounds & Visual Details**: Create atmosphere and depth rather than defaulting to solid colors. Add contextual effects and textures that match the overall aesthetic. Apply creative forms like gradient meshes, noise textures, geometric patterns, layered transparencies, dramatic shadows, decorative borders, custom cursors, and grain overlays — but in this style keep them subtle: faint paper grain, hairline grids, and keyboard-hint chips rather than loud effects.

## Hard constraints for this style

- ONE monospace typeface, used everywhere (headings, numbers, labels, body).
- Pure grayscale + exactly ONE accent (calm blue `#2563EB`), accent only for active/positive state.
- NO neon, NO glow, NO glitch, NO scanlines. This is the calm opposite of cyberpunk.
- Tabular numerals, aligned columns, 1px hairline rules, generous tracking on small uppercase labels.
- A command-palette-first feel: subtle `⌘K`, keyboard-hint chips, a top command bar.
- Sparklines/bars built from block glyphs (▁▂▃▄▅▆▇█) are allowed — elegant, never kitschy.

## Anti-slop rules

NEVER use generic AI-generated aesthetics: overused font families (Inter, Roboto, Arial, system fonts), cliched color schemes (particularly purple gradients on white backgrounds), predictable layouts and component patterns, and cookie-cutter design that lacks context-specific character.

Interpret creatively and make unexpected choices that feel genuinely designed for the context. No two designs should be identical. While this skill commits to the Graphite tone, still vary the specifics (typeface choice, density, layout structure, the memorable detail) per project. NEVER converge on the same predictable choices across generations.

**IMPORTANT**: Match implementation complexity to the aesthetic vision. This is a minimalist, refined aesthetic — it needs restraint, precision, and careful attention to spacing, typography, and subtle details, not elaborate decoration. Elegance comes from executing the vision well.

Don't hold back — show what can truly be created when committing fully to this distinctive vision.
